01

先看清整条流水线，再谈参数

参数面板被切成了十几个分组，但它们在时间上是串行的。点开任意一站， 看它接收什么、交出什么，以及哪些滑块真正作用在这里。

它换掉的不是颜色，是记录方式

普通 LUT 把一个 RGB 三元组映射成另一个三元组。spektrafilm 把你的 RGB 当成场景光的一条线索， 先还出一条连续光谱，让光谱穿过胶片的三层乳剂得到染料密度， 再用光穿过这层密度印到相纸上，最后扫回 RGB。

所以中间流动的是物理量，不是颜色： 曝光 → log 曝光 → CMY 密度 → 光谱密度 → 透射光 → 显示 RGB。 同样一个「+1EV」，在 Film 组和 Print 组的观感完全不同，因为插入的位置不同。

密度衡量的是挡光能力，不是 0 到 1 的亮度。密度加 1.0，透过率变成原来的十分之一。 胶片的 toe、shoulder 和反差，说到底都是这条密度曲线在不同曝光处的斜率。

Beer–Lambert 关系
Lout(λ) = Lin(λ) · 10−D(λ)

整条链反复用这一个式子。密度是对数的，所以叠加密度等于相乘透过率。

为什么非要还原光谱

三层乳剂的感光范围互相重叠。红光除了让红层感光，也会刺激绿层。 用 3×3 矩阵直接近似，饱和色和宽色域素材会崩；先还原成光谱， 再拿真实的感光曲线积分，这种串色是算出来的，不是调出来的。

所以 RGB to Raw 放在 Film 组最上面：它定下了整条链的起点假设。 默认不用动，Hanatos 2026 走可见轨迹 LUT，宽色域最稳。

滤色为什么是反的

青色滤片挡红光，相纸的红层就欠曝。因为负片本身是反的，最终画面反而偏暖。 三个滤色滑块同一套规则：滤片挡什么，画面就偏什么。

Printer Points

另一种计时方式，单位是 1/12 档：2^(points/12)。数值变大，该通道曝光变多。 Gang 让三通道取同一值，Group 保持偏移一起推。

Preflash 恢复的是高光

相纸的趾部在高光端，曝光少就是纸白。所以预闪撑开的是高光层次，把纯白柔化下来。 相纸和负片的 toe 在相反的两头。

质感：颗粒、光晕、扩散，全都长在密度里

这一节最能把 spektrafilm 与其他胶片模拟区分开。颗粒不是盖在成片上的噪声层， 它生成在密度空间里，跟着光一起经过印片和扫描。所以它会被相纸压平，也会被扫描仪锐化。

颗粒是数出来的

颗粒来自卤化银粒子的实际分布。插件先算这个像素在胶片平面上覆盖多大面积， 除以单颗粒子的平均面积，得到候选粒子数；再用密度推出每颗被显影的概率， 最后统计真正显影了多少颗。

中间调颗粒最明显，纯黑纯白处几乎消失，因为概率 p = D / Dmax 在两端逼近 0 或 1，方差自然变小。这是统计的必然，不是画上去的渐变遮罩。

n = Apixel / Aparticle   ·   p = clamp(D / Dmax, 0, 1)
Dgrain = Ndeveloped · Dmax / n Ndeveloped 服从二项分布；插件用高斯近似 + 种子哈希实现，可重复、可动画。

三种颗粒模型

画幅 → 颗粒大小

画幅改的是胶片平面的物理尺寸，不是颗粒生成本身。1080p 和 4K 采样的是同一张数字底片， 只是采样密度不同，结果因此几乎一致。

卤化 Halation

光穿过乳剂后打到片基背面，反射回来又曝光一次。红光敏感层在最里面， 回来的光走的路最长，衰减之后剩下的主要是红光，所以卤化是橙红色的光晕，不是白色泛光。

插件里 Strength RGB 的默认值是 0.05 / 0.015 / 0：红远大于绿，蓝几乎为零。 这组数字是物理结论，不是随手设的。

07

放进 Resolve 的节点树里

插件放在哪个节点，比参数本身更重要。它演的是印片机，所以应该落在技术转换之后、 多数镜头平衡之后。

负片的趾部在暗部，相纸的趾部在高光。

曝光少的时候，负片密度趋近片基，暗部挤在趾部里；相纸则趋近纸白，高光挤在趾部里。 所以 Preflash 作用在纸上，恢复的是高光层次； 想让暗部离开趾部得动 Film Exposure EV； 只想改暗部曲率而不动端点，用 Shadow Shape。

两种常见的放错位置

放在 CST 之后，输出仍设为 Display Out SDR

显示变换做了两遍，高光被压两轮。画面发闷但不发黑，很容易误判成「胶片就该这样」。

在 spektrafilm 之后再大改曝光

胶片响应是非线性的。下游提亮会把已经压进肩部的亮部重新拉起来，得到一片灰雾，不像真的提亮。

spektrafilm 是最后一环，就让它做最终的显示变换；后面还有调色或交付变换，就切到 RCM/ACES。 改亮度请回到 Film 或 Print 的 Exposure EV。
